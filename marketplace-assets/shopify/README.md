## Current Shopify Requirements

- App icon: PNG or JPG, square `1200x1200`, no rounded corners.
- Feature media: prefer a 2-3 minute video; otherwise static image
  `1600x900`, 16:9.
- Screenshots: `1600x900`, 16:9, 3-6 desktop screenshots, at least one app UI.
- Screenshots must be unique and show actual app UI/features.
- Do not include browser chrome, desktop backgrounds, sensitive information,
  pricing, reviews, outcome guarantees, or Shopify branding/trademarks.
- Every image should have alt text.
